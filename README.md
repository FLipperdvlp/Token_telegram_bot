# FileBind — русская визуальная версия

Бот на Python 3.12+, aiogram 3, aiosqlite и SQLite. Сохранены существующая схема БД, транзакционная выдача, защита от дубликатов, подтверждения, история, профиль и админ-панель.

## Windows / PowerShell

Откройте **папку с bot.py** и выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

В `.env` задайте `BOT_TOKEN` (новый токен BotFather), `ADMIN_ID` (числовой Telegram ID) и `DATABASE_PATH=filebind.sqlite3`. Не публикуйте `.env`.

```powershell
.\.venv\Scripts\python.exe bot.py
```

## Использование

- В группе: «🎟️ Взять токен», «📊 Статистика», «👤 Профиль».
- В ЛС владельца: `/start` или `/admin` открывают русскую админ-панель. Для загрузки отправьте UTF-8 TXT до 1 МБ, по записи на строку: `КОД` либо `+12345678901|КОД`.
- `/invalidate 12` исключает доступную запись №12 из пула.
- Файл выдачи с телефоном и токеном отправляется в группу как `issue_<номер>.txt`. После нажатия «Встал» или «Не встал» бот публикует результат и повторно отправляет файл в группу. `/mytoken` в ЛС повторно отправляет файл в группу, а не раскрывает токен в личном сообщении.
- Выдача сохраняется атомарно, а результат можно подтвердить только один раз и только получателю.

## Telegram-ограничения

Файл выдачи и результат «встал/не встал» публикуются в исходную группу; все участники группы смогут открыть и скачать файл с токеном. Добавляйте бота в группу только если такой доступ допустим. Reply-клавиатура не может принудительно отображаться на всех устройствах у каждого участника. Для обработки кнопок в группе может потребоваться отключить privacy mode через BotFather. Для удаления служебных сообщений выдайте боту соответствующее право администратора.

## Оформление

Все тексты интерфейса на русском. Применены карточки с HTML-разметкой, разделители, эмодзи, inline-кнопки, редактируемая админ-панель и индикатор набора текста. Настоящую анимацию HTML/CSS Telegram-сообщения не поддерживают; индикатор набора текста — штатный эффект Telegram.

## Обновление старой установки

Сделайте резервную копию `filebind.sqlite3` и `.env`. Замените исходные `.py` файлы из архива; **не удаляйте базу**. Не запускайте две копии бота с одним токеном одновременно.

## Проверка формата TXT

После загрузки бот сообщает номер строки и причину ошибки, не цитируя содержимое строки. Поддерживаются простые тестовые коды `DEMO_TOKEN_001` и `+48123456789|DEMO_TOKEN_001`. Скрипты `localStorage`/`sessionStorage` и данные авторизации браузера отклоняются; извлечение и передача таких сессий не поддерживаются.
